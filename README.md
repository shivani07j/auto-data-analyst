# Auto Data Analyst

An automated data analysis tool, built in phases. Phase 1 is a manual cleaning and analysis of a messy health dataset, which becomes the blueprint for the tool.

Data: Diabetes 130-US Hospitals (1999-2008), UCI Machine Learning Repository. Download it and place the CSV files in data/raw/.
